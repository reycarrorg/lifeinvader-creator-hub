        Connect Accounts

        OAuth tokens and client secrets are stored natively in Windows Credential Manager — never sent anywhere except Google, Meta, TikTok, or X directly from your PC. Public auto-posting stays locked off.

        YouTubeCHECKING…
        Checking YouTube connection…
        Open Google sign-in link manually ↗
        Google OAuth Setup (Desktop Client)
        1. Open Google Cloud Console → APIs & Services → Library and enable YouTube Data API v3.
        2. Go to Credentials → Create Credentials → OAuth client ID → Desktop app (or Web app with Redirect URI below).
        3. Paste the downloaded JSON (or Client ID + Secret) below and click Save Credentials.
        http://127.0.0.1:3847/api/oauth/youtube/callback

        InstagramCHECKING…
        Checking Instagram connection…
        Open Meta sign-in link manually ↗
        Meta App Setup (Business / Creator)
        1. Keep your Meta app in Development Mode (Meta blocks HTTP login in Live Mode) and add the exact localhost Redirect URI below under Facebook Login → Settings → Valid OAuth Redirect URIs.
        2. Ensure your Instagram Business or Creator account is linked to a Facebook Page, then save App ID + Secret below.
        3. Or skip browser redirect completely: open Meta Graph API Explorer ↗, select your Snapmatic app, grant instagram_basic + pages_show_list, click Generate Access Token, and paste it below (Snapmatic automatically upgrades it to a 60-day token).
        http://localhost:3847/api/oauth/instagram/callback

        TikTokCHECKING…
        Checking TikTok connection…
        Open TikTok sign-in link manually ↗
        TikTok Developer Setup (Desktop Sandbox)
        1. Open TikTok for Developers ↗ → Manage apps → create an app and switch it to Sandbox mode (no public audit needed for your own account).
        2. Add products: Login Kit (Desktop), Display API, and Content Posting API (enable Inbox / Share draft upload).
        3. Under Login Kit → Desktop → Redirect URI, add the exact URI below, and add your TikTok account under Sandbox → Target Users.
        4. Paste your Sandbox Client Key and Client Secret below, save, then click Connect TikTok.
        http://127.0.0.1:3847/api/oauth/tiktok/callback

        X (Twitter)CHECKING…
        Checking X connection…
        Open X sign-in link manually ↗
        X Developer Setup (OAuth 2.0 PKCE)
        1. Open X Developer Portal ↗ → App → User authentication settings.
        2. Enable OAuth 2.0 with Read and write permissions (Native / Desktop App), and add the Redirect URI below.
        3. Paste your OAuth 2.0 Client ID (and Client Secret if confidential app) below, save, then click Connect X.
        http://127.0.0.1:3847/api/oauth/x/callback
